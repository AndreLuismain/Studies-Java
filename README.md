## Estrutura do Repositório

O repositório é organizado por pastas temáticas. Cada pasta representa um conceito ou tecnologia específica. 

Dentro de cada categoria, sigo um padrão de **3 níveis de dificuldade**:
-  **Easy**: Foco na sintaxe e conceitos básicos.
-  **Medium**: Desafios que exigem lógica e integração de conceitos.
-  **Hard**: Problemas complexos que envolvem performance, design patterns ou lógica avançada.
